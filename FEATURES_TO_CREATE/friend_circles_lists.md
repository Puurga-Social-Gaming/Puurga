# Social Features - Friend Circles/Lists

## Status: Missing
## Priority: Low

## Current State
- No custom friend lists or circles
- No way to organize friends into groups
- All friends are in one list
- No granular privacy controls per friend group

## What Needs to Be Created
- Design friend circles/lists system
- Create friend list management UI
- Implement list creation and editing
- Add friends to multiple lists
- Create privacy settings per list
- Integrate with post/story visibility

## Technical Notes
- Database: friend_lists, friend_list_members tables
- UI: Friend lists management page
- Privacy: Extend privacy settings to include custom lists
- Integration: Posts, stories can target specific friend lists
- Default lists: "Close Friends", "Family", "Coworkers", etc.
- Flexibility: Allow users to create custom lists

## Acceptance Criteria
- Users can create custom friend lists
- Friends can be added to multiple lists
- Privacy settings can be set per list
- Posts/stories can target specific lists
- UI is intuitive and manageable
- Lists integrate with existing features
