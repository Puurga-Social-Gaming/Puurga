For Developers

If you're a legitimate developer trying to debug Puurga:

  • Use the browser's DevTools Elements panel instead of console
  • Set NODE_ENV=development to disable console restrictions
  • Check the Network panel for API calls
  • Use React DevTools for component inspection

This protection helps keep our users safe from malicious attacks.
